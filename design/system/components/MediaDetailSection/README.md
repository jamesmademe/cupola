# MediaDetailSection

The detail body's spine: six regions in one fixed order, each labelled by a small sentence-case label the page cannot forget, with fields edited in place on value rows.

Rendered from `lib/core/widgets/media_detail_slot.dart` (`MediaDetailBody`, `MediaDetailSlot`), `media_detail_section_label.dart`, `media_detail_value_row.dart`, `media_detail_body_metrics.dart` and the emitter in `media_detail_view.dart` by `test/design_catalog/media_detail_section_catalog_test.dart`.

- **Order** — `band` → `deck` → `readout` → `operate` → `synopsis` → `reference` → `related`. A page omits a region; it never reorders one. `band` is one line about the whole page, a `FaultBand` over a read that failed or the `InlineErrorRetry` that says a source the answer needs did not answer; it is never put inside the deck. `operate` (the manifest: the file, seasons, albums, missing subtitles) sits above the prose on purpose. Radarr fills `reference` with Details, Scores, then Genres; `related` with Cast and Collection.
- **Rhythm (owned by the spine, never by a caller)** — band: `space-lg` under the hero, unlabelled, and only the centring surplus as its horizontal inset (zero on a phone), because both lines carry the `space-lg` gutter themselves: the glyph lands on the column edge, over the leading edge of the deck. Inside the deck the gutter was paid twice and the glyph sat 16pt in from the actions. Deck: `space-lg` under the hero, or `space-sm` under a band, never labelled, skipped entirely when null; it shares the band's entrance. Readout: `space-md` under the deck, unlabelled, a rail that bleeds off the trailing edge. Every labelled slot: `space-xl` above the label, `space-sm` below it — the asymmetric proximity is the grouping; no dividers, no boxes. An unlabelled slot still buys `space-xl` above it. Horizontal inset: `MediaDetailMetrics.gutterOf` — the `space-lg` gutter plus whatever centres a 720 column (`bodyMaxWidth`) on a wider route; a slot with `measure: MediaDetailMeasure.track` (a table, a grid) runs the full width on the plain `space-lg` gutter, its label with it.
- **Slots** — `MediaDetailSlot.box(child:)` for a widget, `.lazy(sliver:)` for a sliver (a `MediaChildGroupSliver`, built lazily mid-page; an optional `leadingBox` rides above it), `.rail(builder:)` for a horizontal rail handed the resolved gutter so its first item aligns while the row bleeds. Each takes an optional `label`, `count`, `labelAction` and `id`.
- **Label** (`MediaDetailSectionLabel`, built only by the spine) — the slot's label in the micro role (`AppTheme.chrome`, 11 / 600 / 14, the role's own tracking), in sentence case, in the page accent walked by `ServiceTheme.onTint` against `surface` at alpha 0 — the lamp, which resolves to the primary ink — up to two lines. Optional `count`: `space-sm`, then `body-small` tabular in `dimText`, one line, ellipsised. Optional trailing control after `space-sm` (Bazarr's 20pt `Icons.refresh_rounded` `IconButton`, tooltip *Refresh from Bazarr*); past 1.4× reading size the control drops under the label, `space-xs` below it, leading-aligned (offered the full width, so a control that wraps internally still can, but never stretched or centred).
- **Two tracks** — in the desktop shell at `AppBreakpoints.contentWell` (1140) and wider, the slots named in `MediaDetailBody.sideTrack` stand in a 380 column (`sideTrackWidth`) beside the main track, both on the `space-lg` gutter, scrolling as one page; band, deck and readout never move. A page that declares no `sideTrack` falls back to moving `operate` and `related`. A touch build never takes this path.
- **Value row** (`MediaDetailValueRow`) — at least 44 tall, `space-xs` vertical padding. Label in `label-small` 600 `on-surface-variant` (one line), 2pt, value in `body-small` 600 `on-surface` (two lines). Editable: an 18pt `Icons.expand_more_rounded` in `on-surface-variant`; a tap opens one `AppBottomSheet` for that field on a phone (titled with the label, subtitled *Currently HD-1080p*) and a `MenuAnchor` select anchored to the row in the desktop shell. While the write is in flight a 16pt, 2pt-stroke spinner replaces the chevron and the row takes no taps; re-picking the current value writes nothing. A value that matches no option reads `—` in `dimText`, never blank or zero. No write behind it (`onChanged: null` or no options): a plain fact, no chevron, no button role.

The consumer provides a `MediaDetailBody` of slots, each with a sentence-case `label`, and optionally `count`, `labelAction`, `measure` and `id` (the key `sideTrack` addresses, defaulting to the label), plus the page `accent` (the lamp).

Semantics: each label is one header node speaking the original-case label and count (*Seasons, 41 of 45 on disk*); a trailing control keeps its own node. An editable value row is one button: name, value, then the caller's `hint` (*Changes it on Radarr*). On two tracks a screen reader walks the main track, then the side track.

Do: pass labels in sentence case (`'Missing subtitles'`), declare `sideTrack` per slot, and omit an empty slot entirely. Don't: pad a slot yourself, put a sliver in `.box`, or pass a pre-uppercased label — it is read out shouting.

## States in the catalog

Each sheet is drawn in the dark and the light room; the body also in a 1280 desktop window.

- The Radarr and Sonarr pages on a phone, with a fault band over the page, the section labels in each form, the value row editable, unanswered and read-only.
- Text at 200%: the Radarr page, the labels and the value rows.
